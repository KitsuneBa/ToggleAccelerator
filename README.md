# Toggle Accelerator

Streamlines and speeds up the creation of avatar toggles, menus, and animation clips for Standalone, Modular Avatar and VRCFury.

---

## What It Does

Toggle Accelerator automates repetitive avatar setup tasks in Unity. It generates toggle animations, creates parameters, configures menus, and records transform states in seconds, letting you build complex avatar customizers without manual animator editing.

### Key Features

* **Rapid Toggle Setup:** Create GameObject, blendshape, and material toggles with a single click.
* **Modular Avatar & VRCFury Support:** Generates clean non-destructive components ready for upload.
* **Transform Recorder:** Captures object positions, rotations, and scales for props and accessories.
* **Batch Operations:** Quickly process multiple objects or toggle options simultaneously.
* **Test Copy Generator:** One-click quick build to test avatar toggles in play mode before uploading.

## How to Add to VCC (VRChat Creator Companion)

Open the repository listing and click "Add to VCC":  
https://kitsuneba.github.io/KitsuneBaTools/

Or add it manually:
1. Open **VRChat Creator Companion**.
2. Go to **Settings** > **Packages** > **Add Repository**.
3. Paste the listing URL:
   ```
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
4. Click **Add**.
